## 🚀 How to Run

### Server

1. Run `Server.exe` and keep it open.
2. Open `index.html`.
3. Enter the server computer's IP address.
4. Enter your username and press **Enter**.

### Clients

1. Open `index.html`.
2. Enter the server computer's IP address.
3. Enter your username and press **Enter**.

> Port `8000` is added automatically.
> All devices must be connected to the same local network.
